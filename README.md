# Bangladesh MFI Loan Book Analysis

MFIs claim ~98% repayment. This project asks: at what debt-to-income
ratio do borrowers start defaulting, and can loan stacking be detected?

## Structure
- **Part 1:** Real sector data (MRA, MIX Market): concentration, growth, loan size
- **Part 2:** Synthetic loan book calibrated to Part 1: cohorts, stacking, default thresholds

## Data note
Part 1 uses real published data. Part 2 is synthetic and says so clearly.
